# Бот Telegram для автоматизации проверки студенческих работ

## Контейнер: сборка и использование

Ниже описаны базовые шаги для сборки и запуска контейнера. Рекомендуемый способ — через `docker compose`, так как там уже настроены тома и bind-монтирования.

### Запуск через Docker Compose (рекомендуется)

1. Убедись, что установлен Docker.
2. Запусти сервис:
   - `docker compose up -d --build`
3. Посмотреть логи:
   - `docker compose logs -f gasdyn_bot`
4. Остановить и удалить контейнеры:
   - `docker compose down`

### Работа через Makefile

В репозитории есть `Makefile`, который оборачивает основные команды `docker compose`.

- `make build` — собрать образ
- `make up` — запустить сервисы
- `make logs` — посмотреть логи
- `make ps` — список контейнеров
- `make shell` — открыть shell в контейнере `gasdyn_bot`
- `make stop` — остановить контейнеры
- `make down` — остановить и удалить контейнеры
- `make rm` — удалить контейнеры принудительно
- `make rm_image` — удалить образ `unexpectedcoder/gasdyn_bot_image`
